## About GitHub Pages

GitHub Pages turns the static files in a GitHub repository into a public website. In this project:

- `index.html` provides the content.
- `style.css` controls the appearance.
- `script.js` adds interaction in the visitor's browser.

GitHub Pages works well for portfolios, project documentation, learning projects, landing pages, and small browser-based applications. Whenever changes are pushed to the publishing branch, GitHub Pages updates the live website automatically.

It does not run server-side applications such as Python, PHP, or a Node.js server, and it does not provide a database. Features such as user accounts, private data, payments, saved comments, or file uploads normally require a backend hosted elsewhere. A GitHub Pages frontend can still communicate with that backend through an API.

Never put passwords, private API keys, database credentials, or other secrets in frontend files because visitors can inspect everything sent to their browsers.
